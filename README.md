# GESC — Refatoração para Next.js

Branch de trabalho para reconstruir o site do **Grupo de Engenharia de Sistemas Complexos (GESC)** do zero em **Next.js** (App Router + TypeScript), bem componentizado e seguro, usando as API Routes e o roteamento do próprio Next.

O site atual (HTML/CSS/JS estático) está na branch `main` e serve como referência de conteúdo e layout.
